# Sujet nuit de l’info 

## Thème  
Développement Web Full-Stack. 

## Description  
L’objectif est de créer une interface web dynamique et moderne permettant de visualiser le classement d’un concours universitaire de marche. L’interface doit se mettre à jour automatiquement en interrogeant une base de données. 

## Le défi
### Application :  

- UI/UX claire et intuitive pour afficher le classement, avec un compteur indiquant le temps restant jusqu'à la fin du concours 
- Pages d’administrations  (administrateur) : gestion concours, gestion équipes, gestion des utilisateurs (ajout du rôle admin) 
- Pages de gestions d'équipes (utilisateur)  :  créer une équipe, accepter un autre utilisateur dans son équipe, demander à rejoindre une équipe, quitter une équipe, inscrire son équipe à un  défi
- Inscription utilisateur
- Connexion utilisateur / administrateur 
- Toute fonctionnalité supplémentaire est bienvenue et sera prise en compte par le jury 

La mise à jour du nombre de pas des équipes doit se faire automatiquement, sans rechargement manuel de la page. 

Un script SQL pour la mise en place de la base de données est disponible à l’URL fournie. Il est modifiable si nécessaire. N’oubliez pas de l’inclure dans votre dépôt.
